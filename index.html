HCIS (Modern Leave & Attendance Tracker)

Fullstack
PHP Laravel Next.js Tailwind CSS MySQL REST API

Engineered a full-stack Human Capital Information System (HCIS) using Next.js, PHP/Laravel, and MySQL to modernize employee leave tracking and streamline HR approval workflows. Architected a secure, role-based RESTful API utilizing Laravel Sanctum for strict access control, coupled with automated backend business logic via Eloquent ORM to handle dynamic leave balance deductions. The platform features high-performance, responsive dashboards built with Tailwind CSS, delivering a seamless user experience for submitting applications and managing enterprise HR data.
